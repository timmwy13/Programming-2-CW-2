# Programming-2-CW-2
To run this code, make sure you do the following:
Download the Main.java(1.6) and Product.java(1.3) files.
Make sure to rename Main.java(1.6) to Main.java once downloaded.
Make sure to rename Product(1.3).java to Product.java once downloaded.
When putting these files into a Java Project in the src folder, make sure that the package for each file is called system.
Make sure to delete the module-info.java file within the src folder, as it caused issues with many of the Jframe imports.
Once all of the above is fullfilled, run the java project.
